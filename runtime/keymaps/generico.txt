# Key map -- example profile
# Coordinates are per mille of the client area (0..1000), not pixels,
# so the map continues to work when the window is resized.
#
# joystick <four keys> <cx> <cy> <radius>
# The four keys are ordered UP, LEFT, DOWN, RIGHT.
joystick WASD 200 750 120

# touch <key> <x> <y>
touch Q 250 700
touch E 750 700
