Mesa 3D Graphics Library -- and ours is modified
================================================

runtime/bin/opengl32.dll is Mesa, built by this project. It is NOT the
opengl32.dll that ships with Windows, and it is not an unmodified Mesa
build either. Both facts matter to anyone redistributing it.

What exactly is in it
---------------------

    upstream      Mesa 26.2.0, git tag mesa-26.2.0
                  commit 9f0a761020bca92f2b07156a0621e5360cb8eca5
    driver        gallium d3d12 (OpenGL on Direct3D 12), Windows ARM64
    toolchain     MSYS2 CLANGARM64, meson + ninja
    reports       "Mesa 26.2.0" with an empty git hash, because
                  MESA_GIT_SHA1 is empty in this build

Five patches applied on top of that tag. They live in the repository, in
research/mesa-patches/, one file each:

    dxil-hash.patch                 compute the DXIL container hash in
                                    process instead of loading DXIL.dll.
                                    Without it QEMU exits with code 87.
    gallium-static-build.patch      link gallium statically into the WGL
                                    target
    wgl-dep-regex.patch             add the regex dependency to
                                    libgallium_wgl, which otherwise fails
                                    to link with undefined regcomp/regexec
    wgl-context-flush-control.patch implement WGL_ARB_context_flush_control
                                    so a context switch need not wait for
                                    the GPU
    gallium-use-tex-cache.patch     reuse the texture cache

The build tree is research/mesa-src/builddir-win, and the artifact there
is byte-identical to the one shipped:
md5 33730aec0127... for both, verified.
